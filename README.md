# Baza kosmetyków

Automatyczna baza opinii o kosmetykach z kanałów:
- Kacper Skin Ekspert (produkty, zasady łączenia składników, schematy pielęgnacji)
- Kacper Beauty Make-Up (tylko oceny produktów)

Codziennie o 7:00 GitHub sprawdza nowe filmy, Gemini je ogląda, a wyniki trafiają do `docs/data/`.
Wyszukiwarka działa pod adresem GitHub Pages tego repozytorium.

Ustawienia (kanały, data początkowa, dzienny limit) są w `config.json`.
